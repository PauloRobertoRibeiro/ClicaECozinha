# Clica e Cozinha

App para cozinhar em casa: país → cidade/região → receita completa. Não é entrega.

## Receitas

Cada ficha tem pesos, tempos e o **ponto** (o que deve ver). O método é o tradicional do sítio.

Ainda **não** cozinhámos estes pratos nesta cozinha da app. O aviso na ficha é de propósito: não queremos enganar ninguém.

No Espírito Santo: **Vitória** (muqueca capixaba, sem dendê e sem coco) e **Vila Velha** (casquinha de siri).

## Abrir no computador

Pasta `PratoDoDia`. Servidor local:

```
python -m http.server 8091
```

Abrir http://127.0.0.1:8091/
